# 🛡️ LogGuardian AI (2026)

O **LogGuardian AI** é uma ferramenta de Engenharia de Confiabilidade de Sistemas (SRE) desenvolvida em Python que realiza a triagem automatizada de logs de erro em tempo real. Integrado com a API do Google Gemini, a aplicação analisa falhas de produção, determina a Causa Raiz (RCA), sugere correções práticas e notifica equipes de engenharia via webhooks do Discord.

## 🚀 Tecnologias Utilizadas
* **Python 3.13**
* **FastAPI** & **Uvicorn**
* **Google Gemini API** (`gemini-1.5-flash`)
* **Pydantic**
* **Discord Webhooks**
